# Edital Verticalizado TJSP

Site simples para acompanhar o progresso de estudo para o concurso do TJSP.

## Como usar

1. Abra `index.html` em um navegador ou publique com GitHub Pages.
2. Use o botão **Modo Escuro** para alternar o tema.
3. O progresso é salvo no `localStorage`.
4. Você pode exportar o progresso em JSON.

## Publicação

Este projeto pode ser publicado com GitHub Pages diretamente da branch `main`.
